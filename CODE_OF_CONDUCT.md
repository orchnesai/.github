# Code of conduct

We want every Orchnes project to be welcoming for people of every background, language and experience level.

## Expected
- Be respectful and assume good intent; critique ideas, not people.
- Write so others can follow: clear issues, reproducible reports, sources for factual claims.
- Welcome newcomers and non-native English speakers; Turkish and English are both fine in discussions.

## Not acceptable
Harassment, insults, discriminatory language, personal attacks, doxxing, sexualized content, sustained disruption,
and promoting unlawful use of the projects (for example unauthorized hacking or fraud).

## Enforcement
Maintainers may edit or remove contributions and restrict participation for behaviour that breaks this code.
Report problems privately to **info@orchnes.com**, or through **Security → Report a vulnerability** on the repository for sensitive reports.
Reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
