# Security policy

Please **do not open a public issue** for security problems.

## Reporting
1. Preferred: **Security → Report a vulnerability** on the affected repository (private vulnerability reporting is enabled on all `orchnesai` repositories).
2. If you cannot use GitHub: email **security@orchnes.com**.

Include the repository, version or commit, steps to reproduce, and the impact you expect.
We aim to acknowledge reports within 7 days and to publish a fix or mitigation as soon as it is verified.

Repositories may add scope details in their own `SECURITY.md`
(for example [orchnes-360](https://github.com/orchnesai/orchnes-360/blob/main/SECURITY.md) and [orchnes-cli](https://github.com/orchnesai/orchnes-cli/blob/main/SECURITY.md)).
