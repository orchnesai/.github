# .github

Organization profile and default community files for [orchnesai](https://github.com/orchnesai).

- `profile/README.md`: the page shown at github.com/orchnesai.
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md`:
  defaults that GitHub shows on every public repository in the organization that does not have its own copy.
  A repository's own file always wins (for example `orchnes-360` keeps its own contributing guide and issue forms).
